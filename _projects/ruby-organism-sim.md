This is a small artificial ecosystem simulation: Ruby for the simulation logic,
CSV output for state over time, and Python scripts for visualisation. It is
simple, but it connects to an older interest in biological systems and emergent
behaviour.

The useful part was building the loop end to end: define organisms and rules,
run the system, export data, visualise dynamics, and then adjust parameters when
the behaviour is too brittle or too boring.
