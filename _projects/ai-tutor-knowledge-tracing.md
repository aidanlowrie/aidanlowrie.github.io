This prototype explores how a tutoring system might track what a learner can
actually use, rather than only recording material they have encountered. It
represents a subject as a prerequisite graph and maintains a lightweight state
for each concept as the learner completes exercises.

The project is currently an implementation and design experiment. It is not yet
a validated educational product, so it remains unpublished while the learning
model and evaluation approach are developed.
