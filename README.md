# aidanlowrie.com

Personal site. Jekyll, served via GitHub Pages on a custom domain.

## Local development
    bundle install
    bundle exec jekyll serve
Then open http://localhost:4000

## Publishing
Push to `main`. GitHub Pages rebuilds automatically.

## Editing
- Pages: `about.md`, `cv.md`, `now.md`, `writing.md`, `research/index.md`
- Projects: `_projects/*.md`
- Posts: add dated files to `_posts/` (e.g. `2026-09-01-title.md`)
- Site-wide settings (email, social handles): `_config.yml`
